LFXX - AIRAC 2612
=================

Package
- France Military sector file 261201-0001.
- Sector-Files 2612: LFMP update, LFLJ_I_TWR, plugin updates, CDM training lists.
- Squawks are allocated by the NeoRadar server; the manifest no longer carries a squawk section
  (CCAMS removed).

Radar systems (both cdg and neoirma)
- RDF circle 3 NM (it was 0.5 NM), drawn more transparent.
- Detailed tags show the scratchpad, "..." when it is empty (click to edit).
- Compact tags show a small blue "i" when the scratchpad holds text.

2612.2
- Tags: below the transition altitude the altitude reads "A" plus hundreds of feet (A45), using
  the client's own QNH/FL decision.
- Lists with a SID column: the cfl column shows the CFL once set, else the SID's suggested initial
  climb in grey. Added to the sector, CDM NOW and CDM LATER lists.
- Every departure list, CDM ones included, shows the departure airport next to the callsign.

2612.3
- CoFrance maps: a map drawn for one airport's runways while another airport is not in a given
  configuration (CDG with Orly, Orly with CDG) now shows only when that other airport has a
  runway set and none of the listed runways is in use. Before, both variants drew over each
  other whenever the other airport's runways were only partly set (e.g. Orly 25 for arrivals
  only) or not set at all.

2612.4
- EGA Paris-Orly gets CoFrance's Paris-Orly look on the neoIRMA tags: track and tag colours by
  flow with the letter at the base of the leader (P local Orly/Toussus/Villacoublay, O Orly
  arrivals, V Toussus/Villacoublay arrivals, K Le Bourget arrivals, G CDG arrivals, M Orly group
  departures, E CDG/Le Bourget departures, S VFR, X other). S and X follow the altitude filter,
  the others show through it, as in CoFrance. The LFPO AVISO shows the same colours and letters.
- LFPG AVISO opens with its gate/stand, taxiway, building, engine test area and TORA names again.
  The vSMR file now groups them and starts them hidden; label-only groups are shown, as labels
  outside groups always were.
- RDF circle off-white (it was green), and on every transmitting aircraft: it was drawn only at
  or above 3000 ft, so finals, ground and departures never showed one.
- Orly configuration maps (procedure lines, EST LIE / OUEST LIE, the TMA, configuration fixes)
  also draw with arrivals on 02: the departure runway tells east (07) from west (24). CoFrance's
  maps list only 06 and 25 on arrival.
- EGA Paris-Orly in CoFrance Lyon's colours: the airspace you own green-grey, the rest grey, the
  border to an active neighbour green-grey. Orly's map had one flat grey over everything, which
  the build now leaves out so the owned/unowned shading shows.
