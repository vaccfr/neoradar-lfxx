LFXX - AIRAC 2612
=================

Package
- France Military sector file 261201-0001.
- Sector-Files 2612: LFMP update, LFLJ_I_TWR, plugin updates, CDM training lists.
- Squawks are allocated by the NeoRadar server; the manifest no longer carries a squawk section
  (CCAMS removed).

Radar systems (both cdg and neoirma)
- RDF circle 3 NM (it was 0.5 NM), drawn more transparent.
- Detailed tags show the scratchpad, "..." when it is empty (click to edit).
- Compact tags show a small blue "i" when the scratchpad holds text.

2612.2
- Tags: below the transition altitude the altitude reads "A" plus hundreds of feet (A45), using
  the client's own QNH/FL decision.
- Lists with a SID column: the cfl column shows the CFL once set, else the SID's suggested initial
  climb in grey. Added to the sector, CDM NOW and CDM LATER lists.
- Every departure list, CDM ones included, shows the departure airport next to the callsign.

2612.3
- CoFrance maps: a map drawn for one airport's runways while another airport is not in a given
  configuration (CDG with Orly, Orly with CDG) now shows only when that other airport has a
  runway set and none of the listed runways is in use. Before, both variants drew over each
  other whenever the other airport's runways were only partly set (e.g. Orly 25 for arrivals
  only) or not set at all.
